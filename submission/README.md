# Submission package — Water Quality Compliance Estimator

This folder is the final deliverable for **TalTech ITI8612 (Machine Learning),
Spring 2026**.

## Contents

| File | What it is |
|---|---|
| `final_report.md` | Final project report — source (Estonian) |
| `final_report.pdf` | Same report rendered to PDF (≤ 3 pages) |
| `presentation.pptx` | 7-slide deck (English) for the ~5-minute defence |
| `speaker_notes.md` | Speaker notes (English), one block per slide |
| `figures/*.png` | All figures used in the report and the deck |
| `tables/model_comparison.csv` | Authoritative metrics table (4 models × test set) |
| `tables/shap_top10.csv` | Top-10 SHAP feature importances for LightGBM |
| `tables/summary.json` | Aggregate counts (dataset size, class balance, headline metrics) |

The Jupyter notebooks (`notebooks/01`–`07`) and the source library (`src/`) live
in the parent repository; this folder is purely the sealed deliverable.

## Reproduce

From the repository root, with the project venv set up
(`python -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/pip install -e .`):

```bash
# 1. Train LightGBM (other 3 models loaded from cached joblib),
#    write all PNG figures and CSV tables.
.venv/bin/python scripts/export_submission_figures.py

# 2. Build the .pptx from PNG + speaker_notes.md.
.venv/bin/python scripts/build_presentation.py

# 3. Render the PDF (xelatex if available, otherwise weasyprint).
bash scripts/build_report_pdf.sh
```

End-to-end runtime is roughly **2–3 minutes** on a laptop (LightGBM training
plus SHAP on a 2 000-row sample dominate the time).

## Optional manual step

`figures/h2oatlas_screenshot.png` — take a screenshot of
[h2oatlas.ee](https://h2oatlas.ee) (e.g. the Tallinn area with the *model risk*
layer enabled) and save it to that path **before** running
`build_presentation.py`. If the file is missing, slide 6 falls back to a
placeholder card.

  models). The interface contains an explicit disclaimer that the service
  does not replace official assessment.
* All headline numbers in the report and the deck are read from
  `tables/model_comparison.csv`, regenerated by `export_submission_figures.py`.
  Nothing is hand-typed.
