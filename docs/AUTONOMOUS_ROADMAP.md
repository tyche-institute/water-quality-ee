# Autonomous Roadmap

This roadmap is written for direct execution by the agent, not as a general ideas list.

## Phase A: Autonomous Operating System

Goal: make the repository self-steerable.

- establish queue, protocol, and status model
- make trust claims machine-checkable
- encode release-critical wording and validation rules

## Phase B: Trust Surface Hardening

Goal: eliminate overclaim risk across product copy and verification UX.

- centralize trust wording rules
- add automated checks for verify/signature/integrity claims
- make freshness and verification limitations explicit everywhere

## Phase C: Frontend Simplification

Goal: reduce architecture drag in the dashboard.

- decompose controller responsibilities by feature domain
- reduce prop-packet sprawl
- isolate mobile and desktop interaction flows

## Phase D: Data and ML Contracts

Goal: stabilize the production pipeline as a versioned system.

- formalize rule contracts and snapshot contracts
- separate research logic from production publication logic
- add drift and publishability gates

## Phase E: Performance and Observability

Goal: improve public UX under real-world payload constraints.

- reduce snapshot transfer cost
- define performance budgets
- strengthen user-journey telemetry and error diagnostics

## Phase F: Security and Provenance

Goal: tighten operational trust boundaries.

- improve verification path clarity
- encode incident expectations as tests/checks where possible
- harden release and rollback validation

## Phase G: Business Packaging

Goal: prepare the repo and product story for external stakeholders.

- canonical one-page product narrative
- partnership-ready artifact set
- aligned academic / civic / product messaging
